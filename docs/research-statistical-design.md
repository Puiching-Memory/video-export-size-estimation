# 文件大小预测的统计边界与可验证设计

本说明区分数学保证、可执行导出合约、分布假设与经验目标。它不代表实现已经达到这些要求，也不将少量保留来源当作 95% 覆盖证据。

## 连续 CRF 导出的边界

在连续 x264 导出中，片段独立试编码会重置参考帧、GOP、lookahead、码率控制以及 AAC 状态。即使对独立片段大小的抽样估计无偏，也不能因此证明对连续输出无偏。全片低分辨率特征不能给尚未编码内容的高频残差或编码上下文提供普适上界。

反例是 N 个外观特征相近的片段，只有一个具有很大的输出负载。抽取 n 个片段漏掉它的概率是 `(N-n)/N`。若没有事先成立的负载范围，同样的已观察数据既可以来自低负载总体，也可以来自包含任意大负载的总体；小预算下无法给任意输入有限、窄的上置信界。把观察到的最大值当作总体最大值不能修复这个问题。

连续导出可以使用经验模型并通过独立来源组做 conformal 校准。保证来自声明的交换性域，不能继承为任意视频的逐文件无条件保证。完整实际导出的大小和摘要仍是硬体积约束的最终依据。

## 对整条轨迹做一次来源组校准

预先冻结预测算法、候选 CRF 族、有效采样前缀规则、源变体族、seed 策略与全部工具链配置。对每个独立校准来源组 g，定义：

```text
S[g] = max |log(predicted_bytes / actual_bytes)|
       over all registered variants, CRFs, and valid sample prefixes
```

不产生预测的请求需要另行统计拒答，不能删除后只报成功率。若某个预注册请求产生无效或无限分数，它必须进入预先声明的失败规则，不能在看到校准结果后排除。

给定 G 个来源组和覆盖要求 `1-delta`，令 `k=ceil((G+1)*(1-delta))`。若 k 大于 G，校准半径为无穷；否则取第 k 小的组分数 q。新来源组与校准组交换，并且训练与策略开发没有使用校准组时，整条新轨迹满足：

```text
Pr(all registered predictions have actual_bytes in
   [predicted_bytes*exp(-q), predicted_bytes*exp(q)]) >= 1-delta
```

因此该包络覆盖根据观察自适应选择前缀和候选的过程，不必再对每个前缀与 CRF 分摊失效概率。这里不是条件于某个画面类别的逐文件覆盖，也不覆盖未注册滤镜、编码器、线程数、候选配置或随机化策略。

95% 覆盖至少需要 19 个独立校准来源组才有有限分位数；此时半径就是最大的组分数。20 个组仍取最大值。当前只有 7 个校准来源组时，95% 的 k 为 8，必须返回未校准结果，不应降低用户要求或把每段、每个分辨率、每个 CRF 当作新独立来源。增加轨迹中的配置不增加独立样本数。

## 显式独立片段导出

另一种路线是新增独立闭合 GOP 的导出模式。每段以明确帧边界编码，禁止跨段参考，全部滤镜在统一时间线执行，段产物可以复用到最终输出。此模式改变了编码语义，应拥有独立配置、缓存键、参考产物和质量评测。不能把它的误差拿连续单次导出作真值，再宣称两种算法等价。

对固定源、固定配置和确定的编码器，令 `y[i]` 为第 i 段最终所贡献的字节，`H` 为已经精确确定的共同头部与全片音频字节，则：

```text
T = H + sum_i y[i]
```

这才是抽样有限总体；若最终再次有损转码，段大小就不再是这个总体的元素。即使只做 remux，封装变化也需要精确计算或严谨的范围，不能沿用经验常数。

### 字节可加的容器路线

HLS/DASH 文件包的逻辑字节量最容易定义，但与单个 MP4 的大小不同。若目标仍是单个 MP4，可实现并审计一个固定格式的 fragmented MP4 写入器：

- 初始化段只写一次；视频 SPS/PPS 和时间基必须一致，否则拒绝复用。
- 视频每段独立闭合 GOP；已有 AVC 样本原样写入。每个片段使用独立 `moof`/`mdat`，补丁只改固定宽度的序号、轨道号与 decode 时间，不改变长度。
- 全片第一条音轨只编码一次，保留 priming、padding 和起始时间语义。音频片段也是已知字节，其初始化轨道进入共同 `moov`。
- 明确禁用不受控用户元数据与末尾索引；如加入索引，应把它精确计入 H。

例如固定写入单轨片段、64-bit `tfdt`、每个 `trun` 样本都记录 32-bit duration、size、flags 和 composition offset，且 `mdat` 使用 32-bit box 长度时，片段封装长度为 `96 + 16*n_samples` 字节：`moof` 88 字节的固定部分加 16 字节/样本，`mdat` 8 字节固定头。这个数字是上述自有写入格式的设计公式，不是对任意 FFmpeg MP4 的断言；大型 mdat、不同 box 字段、额外轨道或索引会改变它。

必须用独立解析器检查 box 长度、AVC 样本数、关键帧、DTS/PTS、音轨 priming 和总字节，并全片解码验证。CFR 的帧边界和时间基最容易首批验收；VFR、B-frame 重排、编辑后帧率及滤镜对时间的依赖需要各自的时间线规则。按秒 `-ss/-t` 试编码后直接拼接不足以证明没有漏帧、重帧或音频间隙。

### 先验范围必须真实成立

有界抽样区间需要在观察样本之前就成立的 `a <= y[i] <= b`，或每段各自的确定范围。下面这些都不是证明：观察最大段、历史最大值、输入压缩包字节数、原始像素字节数、裸 `-level` 标记、未经合规验证的 VBV 参数、发现超限才报错。

H.264 level 的约束只有在码流实际符合对应语法与 HRD 时才成立。一个更清楚的条件式范围来自 NAL-HRD：若实际码流具有严格峰值到达率 R bit/s、CPB 容量 C bit，且段 decode 时域跨度为 D 秒，漏桶/CPB 约束给出：

```text
NAL coded bytes <= ceil((R*D + C)/8)
```

具体 R/C 应读取 HRD 参数，而不是猜测 CLI 参数。在 H.264 中，HRD 的参数化值为 `(bit_rate_value_minus1+1)*2^(6+bit_rate_scale)` bit/s，以及 `(cpb_size_value_minus1+1)*2^(4+cpb_size_scale)` bit。VCL-HRD 不能直接覆盖额外非 VCL NAL；AVC 长度前缀、初始化参数集和 MP4 封装需单独计入。D 应使用解码时间与初始缓冲约定，不应简单拿未经检查的容器 format.duration 代替。

该公式是实际 HRD 合规的条件性公式。x264 的 VBV underflow/overshoot、缺失 HRD、错误时间戳、用户 SEI 以及 level 标记与实际数据不一致都会破坏假设。检查已编码样本没有违规，不等于证明未编码段将合规。真正的通用语法最坏界还需审计编码器输出与完整规范；本项目当前没有这种证明，不应把宽高乘以一个经验倍数包装成认证范围。

可执行的另一种合约是每段有硬字节 cap，超限中止导出且不发布产物。为统计分析定义有界扩展变量 `z[i] = accepted_segment_bytes`；若该段按协议失败，定义 `z[i] = cap[i]`。对 z 的随机区间有数学依据；最终全部段成功时 `sum z[i]` 等于实际产物字节量。完成之前必须明确 `feasibility_unverified`，而不是承诺一定能产出文件。对全部请求可证明 `Pr(completed artifact AND interval misses its bytes) <= delta`；它不能直接改写成 `Pr(interval misses | completed artifact) <= delta`。若要求后者，还需固定合格输入域、证明全部段都能成功，或额外处理这种选择条件。

如果要保证任意输入均能产出 cap 内有效段，就要定义真正 bounded-output 的回退协议。改变 CRF、分辨率或内容的回退必须进入导出语义和质量约束，不能悄悄把高质量导出换成另一个结果。若质量约束不允许回退，正确响应是不可行或未能验证。

## 有界有限总体的任意时刻区间

固定代表片段之后，可以冻结模型 `m[i]`，从剩余 M 段进行独立随机不放回审计。令残差 `r[i]=y[i]-m[i]`，范围为 `[a,b]`，抽样数 n，总量估计为：

```text
P = H + sum_observed_representatives y[i]
      + sum_remaining m[i] + M*mean_sampled_residuals
```

固定 n 时无偏，但仅固定 n 的标准误差不能处理根据误差停止。一个简单、可复核的同时有效方案给每个候选和前缀分配 `delta/(Q*n*(n+1))`，并使用 Serfling 的双侧范围：

```text
rho_n = 1 - (n-1)/M
radius_n = (b-a)*sqrt(rho_n*log(2/delta_n)/(2*n))
interval_n = P +/- M*radius_n
```

当 n=M 时直接用精确观察总量，区间缩为一点。所有区间还可与已观察字节、未观察段的逐段先验范围相交。宽范围下该公式可能很宽；这是信息成本，不能用没有覆盖定理的正态区间替换后继续声称认证。经验 Bernstein 的有限总体版本可更紧，但必须使用包含先验范围的完整定理和常数，并单独验证实现，不能只将样本方差塞入普通正态公式。

上述审计顺序必须与固定源内容独立。公开固定 seed 加上根据 seed 构造的对抗输入破坏这个条件。实现可先冻结源摘要与候选族，再抽取独立随机审计顺序，记录 seed 以便复现；覆盖解释是对这个随机化过程。若候选族在观测后临时增加，需要新的条件随机化与失效预算，不能自动继承原固定族证书。

## 相对误差和体积旋钮

若真实字节量 T 同时有效地落在正区间 `[L,U]`，使最坏相对误差最小的点估计是：

```text
P = 2*L*U/(L+U)
max_{T in [L,U]} |P-T|/T = (U-L)/(U+L)
```

因此只有 `(U-L)/(U+L) <= requested_relative_error` 才能在覆盖事件内宣称误差目标达到。若 L 为零而 U 为正，就不能满足任何小于 1 的相对误差要求。任意原模型预测 P 也可以保留，但其认证误差需计算 `max(P/L-1, 1-P/U)`，不能仅看区间半宽除以预测。

即使 U 小于硬体积目标，它也是概率性规划证据。最终发布前仍要核对实际全部文件字节、摘要、完整性和音视频语义；没有完整产物时不能承诺硬上限。CRF 不保证逐片段严格单调，也不是感知质量指标。搜索命中一个可行 CRF 不等于找到了全局最佳质量。

## 实测验收与对照

应分别验收 continuous 与 independent-segment 的预测，使用各自真实导出作真值，再额外测量分段对质量、大小、时延与兼容性的代价。已观察段的复用收益要以冷缓存总成本比较，不能把暖缓存结果当首次预测。

至少包含：单个未见高熵 burst、第一次或最后一次采样后停止、单个超 cap 段、VBV underflow、短尾段、B-frame 重排、源在计算中改变、音频 priming/尾填充、非整数 CFR、VFR 与帧率滤镜、相同源不同 CRF、多次候选选择、缓存篡改、片段初始化不一致，以及完整文件音画同步。数学单元测试应枚举小总体的全部抽样顺序和停止规则，核对总失效概率；经验覆盖实验以独立来源组为分母，并同时报告拒答与最终导出失败。

成功标准应写成有限输入域内的运行 SLO：实际预算、误差与覆盖、拒答率、硬上限超限率、独立质量指标和单文件兼容性。新的 16 个来源组适合寻找失效案例和冻结策略，但目前只有 7 个校准组，不能完成 95% 的来源组 conformal 认证，更不能据此宣布行业 SOTA。
